# Данные проекта

- `hotel_bookings.csv` — оригинальный набор бронирований (119 390 строк). Не хранится в GitHub; получить командой `python3 download_data.py` или взять файл преподавателя.
- `hotel_bookings_demo.csv` — **синтетические** демонстрационные данные (3500 строк). Создаются командой `python3 generate_demo.py` либо автоматически в начале Jupyter Notebook.

Готовые сохранённые результаты ноутбука получены на синтетической версии; не выдавайте их за результаты реального отеля.
